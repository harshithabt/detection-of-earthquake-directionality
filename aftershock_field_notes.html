01
THE QUESTION
The study, in numbers

Can metadata explain the angle of shaking?

For each usable record, the workflow estimates the orientation associated with maximum response. For two stations recording the same earthquake, it calculates the smaller angular difference between their orientations. That difference is the regression target.

THE METHOD
Implementation, stage by stage

Follow one record through the code.

The implementation is modular. Each stage creates an inspectable intermediate result, making it easier to identify whether a problem comes from waveform parsing, metadata, pair construction or modelling.

01 / READ

Parse acceleration traces

Read AT2 headers, sampling interval and acceleration samples, and organise the horizontal components.

02 / ROTATE

Estimate the response orientation

Evaluate candidate rotations of the horizontal components using the project's response-analysis procedure.

03 / JOIN

Match record metadata

Associate waveform records with available event, station and site information.

04 / PAIR

Construct same-event pairs

Keep stations recording the same earthquake, then compute the smaller axial difference Δθ.

05 / FIT

Train and compare regressors

Evaluate a distance-only linear benchmark, Ridge regression and an MLP.

06 / CHECK

Test generalisation

Compare MAE, RMSE and R² under a random pair split and a stricter event-held-out split.

NEXT MOVES
Future improvements

Strengthen the evidence before the model.

The current experiments reveal more about the data and validation bottlenecks than about which complex model is best. These are the next steps with the greatest value.

01 / DATA

More independent earthquakes

Expand the waveform set and improve event diversity so model evaluation is not dominated by a handful of earthquakes.

02 / PHYSICS

Audit orientation conventions

Verify component azimuths, AT2 naming, the response period and the paper's selected predictor set.

WHY NEXT ↗

Small convention mismatches can change the target or the input features.

03 / VALIDATION

Test on unseen events

Use grouped event splits, repeated seeds, constant baselines and uncertainty estimates before adding model complexity.

WHY IT HELPS ↗

Pairs can share events and stations, so random pair splits are not fully independent.

Scope note — This is an exploratory academic workflow. It does not predict earthquake occurrence and is not validated for real-time warning or engineering decisions.
06
FIELD Q&A
Implementation viva

What happens under the hood?

Short notes on the core implementation decisions and what should be improved next.

Read the pipeline

Open a question to see the reasoning behind the code design.

How is the target variable generated?

Estimate a maximum-response orientation for each record, pair stations from the same earthquake, and calculate the smaller axial difference. That Δθ value is the regression target.

Why is the target between 0° and 90°?

Orientation is axial: θ and θ + 180° represent the same axis. The calculation takes the smaller of d and 180° − d, keeping the target between 0° and 90°.

Why hold out entire earthquakes?

Pairs from one event can share event conditions or stations. An event-held-out split tests transfer to earthquakes not seen during training.

Why didn't the MLP outperform Ridge?

An MLP can model nonlinear relationships, but it needs enough representative data. The current event sample is limited and the MLP did not outperform the simpler baseline.

What would you improve first?

Increase the number and diversity of records, verify orientation and feature conventions against the reference, then use event-grouped evaluation, repeated seeds and uncertainty estimates.
